CLI harness — not a hosted platform

shagent

Small Bun CLI that talks to OpenRouter and drives tools over the Model Context Protocol (MCP). There is no product domain, dashboard, or multi-tenant “agent platform” here.

This page used to claim a secure hosted platform with sandboxes and SaaS integrations. That was fiction. The real product is the local CLI below.

Run

bun install
export OPENROUTER_API_KEY=sk-or-...
./shagent 'list files in this directory'
  • Default MCP transport: filesystem tools for the current directory
  • Optional model override: SHAGENT_MODEL (default openrouter/free)
  • Source of truth: github.com/michaelmonetized/shagent

See README.md for how the OpenRouter + MCP loop works.
