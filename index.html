Local CLI · not a hosted SaaS

shagent

Small Bun CLI that calls OpenRouter and drives tools over MCP (default: filesystem server for the current directory). This page is docs only — the product is ./shagent in this repo.

Run it

bun install
export OPENROUTER_API_KEY=sk-or-...
./shagent 'list files in this directory'
There is no deploy, no dashboard, and no third-party “Get Started” site. See README.md for the real usage path.
